# GitHub User Finder

A small static web app to lookup and display GitHub user profiles and repositories.

Demo

- Open [github-user-finder](https://denzellsilva.github.io/github-user-finder/) in a browser.
- Search a GitHub user with their username to view their profile and top repositories.

Features

- Search GitHub users by username.
- View profile details (name, avatar, bio, links, stats).
- List public repositories for a selected user.

Files of interest

- [index.html](index.html) — Main search page and app container.
- [profile.html](profile.html) — Profile details page.
- [style.css](style.css) and [fonts.css](fonts.css) — Styling.
- [scripts/index.js](scripts/index.js), [scripts/profile.js](scripts/profile.js) — App logic.
- [scripts/components](scripts/components/) — Reusable UI components.

Development

- Edit UI components in `scripts/components/` and the entry scripts in `scripts/`.
- Keep styling in `style.css` and `fonts.css`.

Enjoy exploring GitHub users!
